## cmd乱码解决：
chcp 65001

## powershell乱码解决：
1. 打开powershell输入
notepad $PROFILE
2. 在打开的记事本中输入：
[System.Console]::OutputEncoding = [System.Console]::InputEncoding = [System.Text.Encoding]::UTF8


# 终端相关命令、快捷键
ctrl + shift + c 外部创建终端
ctrl + shift + ` 内部创建终端

在终端组之间导航:
    下一个Ctrl+PageDown
    上一个Ctrl+PageUp   

Ctrl+Shift+5 窗格拆分
在组中的终端之间导航：
    Alt+Left
    Alt+Right


缓冲区导航
向上滚动一行 - Ctrl+Alt+PageUp
向下滚动一行 - Ctrl+Alt+PageDown
向上滚动一页 - Shift+PageUp
向下滚动页面 - Shift+PageDown
滚动到顶部   - Ctrl+Home
滚动到底部   - Ctrl+End

滚动到上一个命令 - Ctrl+Up
滚动到下一个命令 - Ctrl+向下


# 使用 Alt 重新定位光标
Alt和左键单击会将光标重新定位到鼠标下方。这通过模拟箭头键来实现


# 拖放文件路径
将文件拖入终端将会把路径输入到终端中，并进行转义以匹配活动的 shell。
